# 🏥 End-to-End NHIS Claims Audit Pipeline (Nigeria)

## 📌 Executive Summary
This project builds a full-scale clinical data pipeline analyzing 1,000 synthetic National Health Insurance Scheme (NHIS) claims across major teaching hospitals in Nigeria. The solution uncovers financial leakage patterns, documentation errors, and diagnostic discrepancies.

## 🛠️ Tech Stack & Workflow Architecture
1. **Python (Pandas/NumPy):** Data generation engine mapping regional costs and simulating transactional insurance claims.
2. **MySQL Workbench:** Relational database storage warehouse. Executed conditional aggregations and structural audits.
3. **Power BI Desktop:** Executive presentation tier combining real-time slicers, matrix pivots, and KPI success frameworks.

## 🔍 Core Business Insights
* Evaluated a baseline systemic insurance claim rejection rate of ~19.4%.
* Identified specific surgical and clinical categories experiencing recurring documentation errors due to rigid institutional tariff caps.
* Pinpointed high-density financial loss zones across regional administrative sectors.
